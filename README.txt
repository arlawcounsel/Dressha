A LITTLE WORLD FOR DREESHA — FRONT-END PROTOTYPE

Pages:
- index.html: illustrated garden homepage
- story.html: family, curiosity and childhood creativity
- journey.html: confidence and milestones
- smile-studio.html: playable 30-second tooth-cleaning game
- people.html: support, teaching and purpose
- keepsake.html: closing tribute and hidden note

Files:
- styles.css: shared visual system and mobile responsive rules
- app.js: mobile navigation, story entrance animation, tooth game, secret note
- assets/photos/dreesha-portrait.jpg: reference portrait

Run:
1. Keep the folder structure intact.
2. Open the folder in VS Code.
3. Install Live Server if desired, then right-click index.html > Open with Live Server.
4. Navigate through the page links.

Notes:
- The game works with mouse and touch input.
- Google Fonts load when internet is available; fallback fonts are provided.
- This is a front-end prototype, not deployed.
- Review personal details and image permissions before publishing.
